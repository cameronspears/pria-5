# V5.2 full-frequency comparison

This is a continuous **20 Hz–20 kHz pre-measurement model**, not measured
speaker response. V5.0 and V5.1 share the same acoustic system, so one baseline
trace represents both.

| Metric | V5.0 / V5.1 | V5.2 print candidate |
|---|---:|---:|
| Passive radiators | 1 rear | 2 opposed side |
| Expected net volume | 2.40 L | 2.60 +/- 0.05 L |
| Added mass | 0 g | 7.8 g on each PR |
| Provisional protection HPF | LR4 42 Hz | LR4 40 Hz |
| Modelled F3 | 63.0 Hz | 60.4 Hz |
| 65–250 Hz peak error | +/-2.12 dB | +/-0.98 dB |
| 65–250 Hz RMS error | 1.04 dB | 0.62 dB |
| Modelled 80–200 Hz safe ceiling | 95.4 dB | 96.6 dB |
| Driver CTC | 82.23 mm | 72.23 mm |
| Provisional acoustic handoff | 2.40 kHz LR4 | 2.50 kHz LR4 |
| PIR residual, 1.7–8 kHz | 0.263 dB RMS | 0.183 dB RMS |
| Worst vertical +/-20 deg, XO band | -2.51 dB | -2.09 dB |

The meaningful gains are the smoother and higher-output 65–200 Hz region and
the broader vertical handoff. The tiny wiggles in the nominal mid/HF line are
below the model's uncertainty and must not be equalized before in-box complex
measurements. Final PR mass, crossover polarity/delay, and DSP remain gated by
sealed-cabinet impedance and spin/nearfield measurements.
